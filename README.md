# 系统之美 · 软件工程师互动研习室

一个用原生 HTML / CSS / JavaScript 手写的《系统之美》（Thinking in Systems）互动学习页面，面向软件工程师，把系统思考翻译到代码、发布、值班、故障与团队协作的现场。

它不是电子书摘要，而是一间可以动手的“系统实验室”：把浴缸、恒温器、复利、资源崩溃、系统陷阱、杠杆点和因果回路图，变成可拖动、可观察、可犯错的界面。

每一章末尾都有 **3 道软件工程情境自测**，共 **33 题**。不考背诵，考的是能不能把结构放进代码、发布、值班和团队协作的现场。

## 打开方式

直接双击 `index.html` 即可，无需安装任何依赖。也可以在当前目录启动一个静态服务器：

```bash
python3 -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000
```

页面完全离线运行，不依赖 CDN、外部字体或图片。

## 交互与体验

- 每章末尾有 3 道工程情境自测，即时判分、解释，并保存在本地。
- 进度按模块保存在浏览器 `localStorage` 中；章节底部可点亮 / 取消完成。
- 完成自测后，章节完成按钮会提示“可以点亮本章”。
- 知识地图随时打开；顶部可切换明暗主题。
- 音效默认关闭。打开后，拖动滑杆、答题、完成章节会有轻微的合成音效；没有音频文件。
- 沙盒支持添加 / 重命名 / 删除变量、建立带正负极性的因果链、拖动布局、自动探测回路，并自动保存当前画布。
- 支持桌面和手机；菜单在窄屏下变成抽屉。
- 全书约 33 道章节自测 + 10 道终测，自测答案会本地保存，可单独重做。
- 支持 `prefers-reduced-motion`，并提供了打印 / 存为 PDF 的速查版式。

## 技术说明

- 纯原生：HTML + CSS + JavaScript，无框架、无构建步骤、无第三方依赖。
- 图表由 Canvas 2D 绘制，系统网络由 SVG 绘制，音效由 Web Audio API 实时合成。
- 模拟采用简化的教学模型，用来呈现行为模式与反馈结构，不用于预测真实系统。
- 文案中的中文译名参考《系统之美》常见中译本；示例、图表、交互和工程类比为原创教学演示。

## 内容与边界

内容框架致敬 Donella H. Meadows 的 *Thinking in Systems: A Primer*，并面向软件工程语境重新组织。覆盖原书的核心概念：系统三要素、存量流量、反馈与延迟、三大系统特征、六个认知障碍、八个系统陷阱、十二个杠杆点和十五条与系统共舞的法则。

这是一个教学演示，不是原书的替代品，也不声称复现原书全部案例。它更适合作为：

1. 第一次读《系统之美》时的“可视化词典”；
2. 读完之后的回路练习场；
3. 软件团队复盘时，用来把“事件”翻译成“结构”的讨论工具。

> 系统的行为，来自它的结构；要改变行为，就要改变结构——而改变结构，首先要看见结构。
